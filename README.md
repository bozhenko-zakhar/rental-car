# 🚗 **RentalCar — платформа для тимчасового найму автомобілів**

## Короткий опис

**RentalCar** — це веб-застосунок для тимчасового найму автомобілів. Користувач може переглядати каталог машин, фільтрувати їх за різними параметрами, переглядати детальну інформацію про авто та залишати заявку на оренду.

Проєкт створений із використанням сучасного front-end (React, Next.js, TypeScript, TanStack Query, Axios, CSS Modules) стеку й орієнтований на зручний та швидкий користувацький досвід.

---

## ✨ Основні функції

* перегляд каталогу автомобілів;
* фільтрація за брендом, mileage та вартістю;
* infinite loading через `useInfiniteQuery`;
* детальна сторінка автомобіля;
* форма створення заявки на оренду;
* взаємодія клієнта і сервера через REST API.

## 🚀 Встановлення та запуск

### Встановлення залежностей

```bash
npm install
```

### Запуск проєкту

```bash
npm run dev
```

## 📖 Використання

1. Відкрити головну сторінку;
2. Перейти до каталогу автомобілів;
3. Використати систему фільтрації;
4. Обрати потрібний автомобіль;
5. Переглянути детальну інформацію;
6. Заповнити форму для створення заявки на оренду.
